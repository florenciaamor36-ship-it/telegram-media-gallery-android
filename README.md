# La Clave Play — catálogo abierto

Aplicación Android de prueba para buscar y reproducir videos de dos fuentes abiertas: Internet Archive y Wikimedia Commons. La interfaz y el reproductor son propios; cada resultado muestra su fuente, derechos disponibles y enlace a la ficha original.

## Incluye
- Búsqueda de videos públicos de Internet Archive.
- Búsqueda de archivos de video de Wikimedia Commons.
- Reproducción con AndroidX Media3 y enlace a la ficha fuente.
- Catálogos separados para distinguir procedencia y licencias.

## Fuera del alcance
No incluye Pluto TV ni Telegram.

## Derechos y disponibilidad
La disponibilidad, formato y licencia cambian según el elemento. Revisar la ficha original y las condiciones territoriales antes de reutilizar o redistribuir cualquier obra. Los metadatos se muestran como referencia y no constituyen una validación jurídica. Algunos formatos pueden no reproducirse en todos los dispositivos.

## Build
Build debug ARM64 mediante GitHub Actions. La compilación exitosa no sustituye la prueba de reproducción en un dispositivo físico.
